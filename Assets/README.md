# Assets — куда класть файлы

```
Assets/
├── Backs/   рубашки карт: 01.png … 27.png   (у каждой карты своя)
├── Faces/   лицевые стороны: 01.png … 27.png
├── Logo/    logo.png — значок в левом верхнем углу (по желанию, высота 26 px)
│            favicon.png — значок вкладки браузера (по желанию; без него берётся logo.png)
├── Intro/   intro.png — картинка вступительной заставки (по желанию)
├── Sheet/   character-sheet.png              (лист персонажа, 2480×3508)
├── Fonts/   файлы шрифтов (.woff2 / .ttf / .otf) с кириллицей
└── Sounds/  звуки: ambient.mp3, click.mp3, card-select.mp3 … (список в Sounds/README.md)
```

- Номер в имени файла — это поле `number` карты в `js/data/cards.js`. Двузначный: `01.png`, `09.png`, `27.png`.
- Регистр имён важен: на GitHub Pages `01.PNG` и `01.png` — разные файлы. Используйте `.png` строчными.
- Если имена у вас другие, не переименовывайте файлы: укажите `backFile` / `faceFile` у карты в `cards.js`.
- Чего не хватает, покажет команда `node tools/check-assets.mjs`.
- Пока файлов нет, программа работает на временных заглушках.
- Вес: желательно, чтобы карта была до 500 КБ. Лист весит больше, это нормально.
