# Assets/Sounds — репозиторий звуков

Положите сюда звуковые файлы с **этими именами** — сайт подхватит их сам. Нет файла — это событие просто молчит.

| Файл                 | Когда играет                                         | Громкость по умолчанию |
|----------------------|------------------------------------------------------|-----|
| `ambient.mp3`        | общий фон (зациклен, начинается после первого касания) | 0.35 |
| `click.mp3`          | нажатие любой кнопки, **кроме «пропустить»**          | 0.6 |
| `card-select.mp3`    | карта выбрана                                        | 0.8 |
| `card-deselect.mp3`  | выбор карты снят                                     | 0.6 |
| `cards-deal.mp3`     | 27 карт раскладываются по экрану                     | 0.8 |
| `card-flip.mp3`      | каждый переворот карты на финальном экране           | 0.9 |
| `sheet-ready.mp3`    | лист персонажа готов                                 | 0.9 |

- Формат другой (`.ogg`, `.wav`, `.m4a`)? Не переименовывайте, а поправьте расширение в `js/data/sounds.js`.
- Громкость и отключение отдельных звуков — там же (`volume`, `null`).
- Фон запускается сразу при заходе, но браузеры (Chrome, Safari, Firefox) обычно запрещают звук без касания страницы. Тогда фон начнётся при первом клике или нажатии клавиши (на заставке тоже). Обойти это нельзя; иногда Chrome разрешает автозапуск сайтам, которыми часто пользуются.
- В правом верхнем углу есть кнопка, которая выключает все звуки.
- Советы: клики и карты — короткие (до 1 секунды), фон — 1–2 минуты без резкого начала и конца (иначе зацикливание будет слышно), вес — до 1–2 МБ. Берите звуки, на которые у вас есть права (свои, CC0 или купленные).
