# RollSet — лист персонажа для «Глюфонде»

Браузерный генератор: игрок вводит имя, выбирает три архетипа из 27 карт (или доверяется судьбе), программа складывает модификаторы девяти навыков и выдаёт заполненный лист персонажа в PNG и в PDF формата A4.

Сайт статический: HTML, CSS и ES-модули, сборки нет. Ничего не сохраняется между перезагрузками (нет localStorage, sessionStorage, IndexedDB и cookies).

> **Сейчас в проекте тестовые данные.** Названия карт, модификаторы, текст механики и координаты полей на листе выдуманы для проверки программы. Настоящие данные игры нужно подставить (см. ниже).

## Быстрый старт

Открывать `index.html` двойным щелчком нельзя: браузеры запрещают ES-модули (и холст с картинками) при адресе `file://`, поэтому кнопки не работают. Нужен локальный сервер. Самые простые способы:

- **Windows:** дважды щёлкните `start-windows.bat`. Ничего устанавливать не нужно, откроется браузер. Окно держите открытым, пока пользуетесь сайтом.
- **macOS / Linux:** дважды щёлкните `start-mac-linux.command` (нужен python3). Если система не даёт запустить файл: `chmod +x start-mac-linux.command`.
- **Любая система с Python:** `python3 -m http.server 8080` в папке проекта и открыть http://localhost:8080.

Если страницу всё же открыли двойным щелчком, она сама покажет подсказку.

**Калибровка листа:** `start-calibrate-windows.bat` (macOS / Linux: `start-calibrate-mac-linux.command`) открывает сразу `calibrate.html`. Обычные `start-…` открывают сам сайт.

Тесты: `npm test` (Node 20+, внешних зависимостей нет).

## Что подставить своё

| Что | Где | Подсказка |
|---|---|---|
| Рубашки и лица карт | `Assets/Backs/NN.png`, `Assets/Faces/NN.png` | `NN` = номер карты, двузначный: `01`…`27` |
| Картинка заставки (5 с) | `Assets/Intro/intro.png` | по желанию; длительность в `js/config.js → intro` |
| Лист персонажа | `Assets/Sheet/character-sheet.png` | 2480×3508 |
| Названия и модификаторы карт | `js/data/cards.js` | `number` пишется без нуля впереди (`1`, а не `01`): иначе сайт не запустится. Файлы при этом называются `01.png` |
| Описание механики | `js/data/mechanics.js` | поставить `isPlaceholder: false` |
| Координаты полей на листе | `js/data/sheet-layout.js` | подгоняются мышью в `calibrate.html` |
| Шрифты | `Assets/Fonts/` + `js/data/fonts.js` | нужна кириллица |
| Правила (число карт, тайминги, «судьба») | `js/config.js` | |

Проверка комплектности: `node tools/check-assets.mjs`.

### Калибровка листа

1. Положите лист в `Assets/Sheet/character-sheet.png`.
2. Запустите `start-calibrate-windows.bat` (откроется `calibrate.html`). Рамки: красная — имя, зелёные — архетипы, синие — навыки.
3. Перетащите рамку на поле, потяните за кружок в углу, чтобы изменить размер. Числа и выравнивание можно ввести вручную, стрелки двигают на 1 px (Shift — на 10).
4. Пробный текст внизу показывает, как лягут длинное имя и разные числа. Текст сам подбирает размер шрифта между `maxFont` и `minFont`.
5. Нажмите «Скопировать» и вставьте код в `js/data/sheet-layout.js` вместо прежнего `LAYOUT`. Уберите строку `isTestLayout: true`, если она осталась.

### Подключение шрифта

1. Положите файл в `Assets/Fonts/` (лучше `.woff2`). Проверьте кириллицу и лицензию (сайт + картинки).
2. В `js/data/fonts.js` добавьте строки в `FONT_FILES`. Три роли: `RollSet Sheet` (текст на листе), `RollSet Display` (заголовки), `RollSet Body` (основной текст). Один файл можно подключить ко всем трём.
3. Обновите страницу; в `calibrate.html` есть строка проверки кириллицы.

## Публикация на GitHub Pages

1. Создайте на GitHub репозиторий (например, `rollset`). Публичный: на бесплатном тарифе Pages работает только с публичными.
2. Загрузите в корень репозитория всё содержимое этой папки: **`index.html` должен лежать в корне**, а не внутри вложенной папки. Через сайт: Add file → Upload files, перетащите файлы и папки. Через git:
   ```bash
   git init && git add . && git commit -m "RollSet"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/rollset.git
   git push -u origin main
   ```
3. Откройте Settings → Pages. В блоке Build and deployment выберите Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, нажмите Save.
4. Через 1–2 минуты сайт появится по адресу `https://<ваш-логин>.github.io/rollset/`. Статус виден на вкладке Actions.
5. Откройте сайт и пройдите весь путь до скачивания PNG и PDF. Если вместо картинок заглушки, проверьте регистр и расширение файлов: на Pages `01.PNG` и `01.png` — разные файлы.

Файл `.nojekyll` в корне уже есть: он отключает обработку Jekyll, чтобы папки не терялись.

Обновление сайта: загрузите изменённые файлы в репозиторий и подождите минуту. Если браузер показывает старую версию, обновите страницу с Ctrl+F5.

## Как это работает

- `docs/ARCHITECTURE.md` — модули, конечный автомат, поток данных.
- Игровые данные отдельно от логики: `js/data/` и `js/core/`.
- Ядро не зависит от DOM и покрыто тестами в `tests/`.

## Сценарий

1. Приветствие: «Прочитать механику» или «Пропустить».
2. Имя (1–32 символа).
3. Выбор трёх карт. Закрытые карты показывают только название.
   - «Пусть судьба решит за меня» выбирает три разные карты. «Принять судьбу» фиксирует их, «Выберу сам» возвращает к ручному выбору без нового броска.
   - Ручной выбор подтверждается отдельным окном.
4. После подтверждения архетипы нельзя изменить. Карты по очереди переворачиваются лицом вверх.
5. Суммируются модификаторы девяти навыков.
6. Лист собирается на оригинальном PNG; скачивание PNG и PDF A4.

## Ограничения прототипа

- Базовых значений навыков нет: итог — это сумма модификаторов трёх карт. Если в игре есть базовые значения, их надо добавить в `js/core/skills.js`.
- В PDF картинка листа встроена как JPEG (качество 95 %): так файл получается компактнее. PNG сохраняется без потерь.
- Предпросмотр листа и экспорт используют один и тот же холст 2480×3508 пикселей. На очень старых телефонах такой холст может не создаться: тогда будет сообщение об ошибке.
